## TermiAI
An AI client do terminal job just for you :)
### If you scared to type terminal commmand ...
Use This!! An AI will run commands just for you

### Installation guide:

#### For Windows

- Download Windows installer from [here](https://github.com/Ericwasepic127/TermiAI/releases)
1. Select latest release one.
2. Dismiss SmartScreen and press Run anyway.
3. Follow on-screen instructions to install TermiAI

#### For Linux (Ubuntu, Debian, Linux Mint, ...)

> [!WARNING]
> This won't work on Linux distros' that don't use apt and/or based on libapt-pkg package managers. Does not work on Termux.

1. Install certficates and needed tools. `sudo apt-get install ca-certificates curl`
2. Run the installer. `curl -fsSL https://termiai-apt.onrender.com/install | sudo sh`
3. Done! It includes icon and app finder's launcher

#### Downloading from source (any Operating System)

1. Install Python (at least 3.13). You can follow [this instructions.](https://ericwasepic127.github.io/supy3guide/installing.html)
2. Then, run `pip install terminal-assistant-interface` (Windows) or `pip3 install terminal-assistant-interface --break-system-packages` (macOS/Linux)
3. Launch **TermiAI** by `termiai-source` command!
  - There's no icons, launcher for this
